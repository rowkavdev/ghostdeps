# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

In short: be respectful and constructive; no harassment, personal attacks, or discrimination; critique code, not people. Project maintainers may remove, edit, or reject comments, commits, issues, and other contributions that violate this code, and may ban contributors for behaviour they deem inappropriate.

The full text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Reports: open a private report via GitHub (Security → Advisories) or contact the maintainer at rowkav0809@gmail.com
